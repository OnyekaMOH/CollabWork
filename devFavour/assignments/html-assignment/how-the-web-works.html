What Really Happens When You Visit a Website?

You type a website address, press Enter, and within seconds, a webpage appears on your screen.

Simple, right?

But behind that little action, several technologies are working together to make it happen.

Let's uncover some of the magic.

Your Browser Doesn't Know Every Website's Address

Have you ever wondered how your browser knows where to find a website?

That's where DNS (Domain Name System) comes in.

Think of DNS as the internet's address book.

When you type a domain name like example.com, DNS helps your browser find the corresponding IP address needed to connect to the website's server.

Without DNS, navigating the web using memorable names would be much more difficult.

What Happens Next?

  1. You enter a URL: Your browser identifies the website you're requesting.
  2. DNS helps find the address: The domain name is resolved to an IP address, unless that information is already cached.
  3. Your browser sends a request: It uses HTTP or HTTPS to request resources from the server.
  4. The server responds: It returns the requested resources or an appropriate response, such as an error.
  5. Your browser displays the page: It processes the received content and renders what you see.

And all of this can happen incredibly quickly.

Information Travels in Tiny Packets 📦

Here's something interesting: when information travels across the internet, it isn't necessarily sent as one giant piece.

Instead, data is divided into smaller units called packets.

Each packet carries information that helps the network deliver it to the correct destination.

These packets can travel across different network routes before their data is processed and reassembled.

Why does this matter?

Breaking information into packets allows networks to transport data efficiently and makes it possible to recover from some transmission problems without sending everything again.

So the next time you load a website, remember that the information on your screen has travelled through a network to reach you.

Your Browser Is Doing More Than Displaying Text 👀

When a browser receives a webpage's files, its work isn't finished.

It must interpret the resources and turn them into something you can see and interact with.

Three important technologies often work together:

  • HTML: Defines the content and structure of the webpage.
  • CSS: Controls its appearance and presentation.
  • JavaScript: Can add interactivity and dynamic behaviour.

The browser processes these resources, calculates the layout, and draws the page onto your screen.

That beautiful website you see is the result of several processes happening behind the scenes.
